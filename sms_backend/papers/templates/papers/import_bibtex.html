How to Export BibTeX from Popular Tools
From Zotero:
  1. Select papers in your library
  2. Right-click → Export Items
  3. Choose "BibTeX" format
  4. Save and upload here
From Mendeley:
  1. Select papers
  2. File → Export
  3. Choose "BibTeX (*.bib)" format
  4. Upload the exported file
From EndNote:
  1. Select references
  2. File → Export
  3. Choose "BibTeX Export" output style
  4. Save and upload
